# Use Spring Boot for the backend

Java + Spring Boot serves the REST API: JPA/Hibernate, Bean Validation, Spring Security with method security, Flyway migrations, and Testcontainers-tested transactions. Chosen because the portfolio targets junior-to-strong-junior Spring skills (DI, DTOs, validation, transactions, security, testing) and the ecosystem covers every one of them. Alternatives (Quarkus, Micronaut) are fine but less asked-for in interviews.
